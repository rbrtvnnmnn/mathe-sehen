# Sehen & Verstehen

Interaktive Übungen für alle, die verstehen statt auswendig lernen wollen. Die Idee: Was man einmal gesehen hat, versteht man. Und was man versteht, muss man nicht auswendig lernen.

Angefangen hat es mit Mathe („Mathe sehen“). Weitere Fächer sollen nach und nach dazukommen.

## Die Übungen

Alle Übungen in der empfohlenen Reihenfolge stehen auf der Übersichtsseite: https://rbrtvnnmnn.github.io/sehen-verstehen/

Jede Übung endet mit Aufgaben zum Selberrechnen.

## Benutzen

- **Online:** https://rbrtvnnmnn.github.io/sehen-verstehen/
- **Offline:** Repository als ZIP herunterladen, entpacken und `index.html` im Browser öffnen.

Es gibt nichts zu installieren. Die Seiten funktionieren auf Computer, Tablet und Handy.

## Datenschutz

Keine Anmeldung, keine Werbung, kein Tracking. Die Seiten speichern und verschicken keine Daten. Auch die Schriften liegen im Repository, es gibt also keine Verbindung zu fremden Servern.

## Mitmachen

Fehler gefunden oder eine Idee für eine neue Übung? Gern als Issue eintragen.
